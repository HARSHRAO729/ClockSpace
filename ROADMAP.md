# ClockSpace Roadmap 📍

Our goal is to be the #1 destination for discovering and installing open-source macOS screensavers.

## 🟢 Phase 1: Core Experience (Complete)
- [x] Basic Marketplace UI.
- [x] Firebase-backed catalog.
- [x] Automatic .saver installation.
- [x] Glassmorphic "Apple Look" UI.
- [x] Permission fallback system.

## 🟡 Phase 2: Refinement (In Progress)
- [ ] **Security-Scoped Bookmarks**: Persist folder access across app restarts without re-prompting.
- [ ] **Auto-Update**: Check for new versions of installed screensavers.
- [ ] **Search Engine**: Better tagging and algorithmic discovery.
- [ ] **Localization**: Support for more languages.

## 🔴 Phase 3: Community & Scale (Upcoming)
- [ ] **User Accounts**: Sync "Liked" savers across Macs.
- [ ] **Developer Portal**: A way for screensaver creators to submit their work directly.
- [ ] **Screensaver Customization**: In-app UI for configuring screensaver options (plist editing).
- [ ] **Dynamic Backgrounds**: Support for 24-hour wallpapers/screensavers.

---

## 💡 Good First Issues for New Contributors
- [ ] Fix small UI alignment issues in `DashboardView`.
- [ ] Add more screensaver metadata to `catalog.json`.
- [ ] Improve documentation in `FileSystemService.swift`.
- [ ] Implement a "Share" button for screensavers.
